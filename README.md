# 영어 공부 · H-class

과외 필기(148쪽)를 기반으로 만든 모바일용 문법 노트입니다.

- **H-class**: 문법 19챕터, 영작 연습 92문장(카드/목록), 오답노트
- **TOEIC 850+ / Speaking IH**: 추가 예정

## 구조
- `data.js` — 챕터 내용 (여기만 고치면 내용이 바뀜)
- `app.js` — 화면 동작
- `styles.css` — 디자인
- `sw.js` — 오프라인 캐시 (내용 수정 후 `VERSION`을 올리기)

## 휴대폰 홈 화면에 추가
- iPhone: Safari로 열기 → 공유 버튼 → **홈 화면에 추가**
- Android: Chrome으로 열기 → ⋮ 메뉴 → **홈 화면에 추가**
